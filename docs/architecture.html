Executive Summary

A production-grade, security-hardened AWS deployment using Terraform IaC. Built on real-world patterns from BP Refinery, Patterson UTI, and Mammoth Energy Services. Implements a Zero Trust network architecture with a 3-AZ VPC, EKS 1.29 with IRSA and Karpenter, RDS Aurora PostgreSQL Multi-AZ, CloudFront CDN with WAFv2 OWASP managed rules, and a full observability stack with GuardDuty, Security Hub, VPC Flow Logs, and Athena analytics. Modules are aligned to NIST 800-53, CIS EKS Benchmark, HIPAA, SOC 2, and CMMC compliance frameworks.

Data Flow / Request Flow

  1. DNS Resolution -- Route 53 resolves the application domain to the CloudFront distribution.
  2. Edge Security -- CloudFront serves cached content and forwards dynamic requests through WAFv2 (OWASP managed rules + custom rate limits).
  3. Load Balancing -- The ALB in public subnets distributes traffic across EKS pods in private subnets.
  4. Application Processing -- EKS pods (app/ML/system node groups) process requests using IRSA for secure AWS service access.
  5. Data Access -- Applications connect to Aurora PostgreSQL (Multi-AZ, encrypted), ElastiCache Redis, and S3 in isolated data subnets.
  6. Security Monitoring -- VPC Flow Logs stream to S3 for Athena analysis. GuardDuty monitors for threats. Security Hub aggregates compliance findings and alerts via SNS.

Production Readiness Checklist

  • Configure Terraform backend with S3 + DynamoDB state locking
  • Set up AWS credentials with least-privilege deployment role
  • Review and customize prod.tfvars for environment-specific settings
  • Validate VPC CIDR ranges and subnet allocations for the deployment region
  • Configure EKS node group instance types and scaling limits
  • Set RDS backup retention, maintenance window, and performance insights
  • Configure WAFv2 custom rules for application-specific protections
  • Enable GuardDuty, Security Hub, and CloudTrail in the deployment region
  • Set up SNS notifications for security findings
  • Run terraform plan and review all changes before apply
  • Configure VPC Flow Logs with Athena query workspace

Deployment

Local Development

git clone https://github.com/kogunlowo123/aws-enterprise-deployment.git
cd aws-enterprise-deployment/terraform/environments/prod
terraform init
terraform validate
terraform plan -var-file=prod.tfvars

Production Deployment

cd terraform/environments/prod
terraform init -backend-config=backend.hcl
terraform workspace new prod
terraform plan -var-file=prod.tfvars
terraform apply -auto-approve

# Post-deployment verification
aws eks update-kubeconfig --name cluster
kubectl get nodes
